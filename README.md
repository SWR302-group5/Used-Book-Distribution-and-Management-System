## Project Overview
The **Used Book Distribution Standardization and Management System (UBDS)** is an independent enterprise software platform designed to standardize physical condition grading (5-Tier Condition Scale), orchestrate omnichannel inventory management (in-store POS vs. online e-commerce), and coordinate consignment book lifecycles across retail branches.
